# 90-archive — холодное

То, что вышло из активного внимания, но не удалено: записи инбокса, провисевшие неделю без рода (режим strict триажа), упразднённые разделы, следы миграции, снятые реестры. Архив обратим — холод, а не удаление; wikilinks на архивное продолжают работать.

Архив каждого реестра цепочки живёт **рядом с реестром** (`10-governance/<реестр>/archive/`), а не здесь: решённая неудовлетворённость и закрытый проект сохраняют свои ссылки и видны Dataview-видам реестра. Сюда уходит то, у чего живого реестра больше нет.
