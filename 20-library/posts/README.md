# 20-library/posts — датированные тексты

Текст, привязанный к моменту: `type: post`, после публикации не меняется; при публикации ставятся `published: YYYY-MM-DD` и `link`. Заводится `80-kernel/templates/text-tmpl.md` — из черновика, тогда текст идёт в серию практики письма. Перечень каналов в `channels` — ваш (ADR-0012).
