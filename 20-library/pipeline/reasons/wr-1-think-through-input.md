# WR-1 — Помыслить входящее

> Обработать входящую информацию, чтобы она «осела». То есть помыслить.

Повод письма. Обращён: внутрь. Формулировка — авторская; перепишите её своими словами, а набор поводов перекройте по своим текстам: поводы не сочиняются, а находятся сверкой с уже написанным.

**Отличительный признак:** вход — чужой материал, письмо его перерабатывает.
