# EN-1 — Мимолётная заметка

Первый вход творческого конвейера. Носитель — лоток: записи копятся и ждут разбора.

**Где лежит:** [[fleeting-notes|00-inbox/fleeting-notes.md]], одна запись — один пункт списка, начинается с даты.

**Кто пишет:**

- владелец — напрямую за компьютером;
- агент — в сессии по просьбе;
- любой другой канал захвата, который вы подключите (например, бот с телефона), — допишите его в `writers`.

**Правило записи:** слова владельца — дословно; слова агента — отдельной строкой с пометкой `↳ агент:`; пересланное — ссылкой и строкой о том, что это. Метка источника не нужна: размечаются только слова агента, кто бы из агентов их ни писал. Правило стоит шапкой-цитатой в самом лотке.

**Разобрано, когда** запись удалена из файла: перенесена в черновик, задачу, карточку задачи или проекта — или выброшена («нет проекта — нет заметки», третья судьба заметки по МИМ). Разбор — раз в неделю на стратегировании.

**След:** исходная дата записи едет в место назначения.

**Подсчёт неразобранного** (`top-level-lines`): каждая непустая строка лотка вне frontmatter, которая начинается не с пробела и не с `>`, — одна запись. Продолжение записи пишется с отступом и не считается, шапка-цитата тоже. Старейшая запись — по первой дате вида `ДД.ММ` или `ДД.ММ.ГГГГ` в такой строке.
