# EN-4 — Рабочая находка

Четвёртый вход конвейера. Это мысль, рождённая делом, а не чтением. Носитель — лоток-папка: каждая находка — отдельный файл, а разбор — перенос файла в папку заметок.

**Где лежит:** `00-inbox/findings/<находка>.md`, `type: finding`. После разбора — `20-library/resources/9-notes/`, рядом с образовательными заметками: тот же плацдарм, только источник — собственная практика.

**Файл — это находка, а не предмет.** В файле копится контекст вокруг одной находки, пока она исследуется. Новый материал по тому же предмету — новый файл, а не дописывание старого.

**Кто пишет:** по очереди владелец и агент, с которым разбирается рабочий вопрос. Поэтому класс файла — `writer: mixed` (INV-19): исключение из правила «один writer на файл», объявленное во frontmatter.

**Зачем:** **выход в черновик обязателен** — это капитал рабочих публикаций. Вход питает повод [[wr-4-pass-on|WR-4]] (передать).

**Разобрано, когда** файл перенесён в `9-notes/` и в его свойстве `drafts` есть ссылка на черновик. Разбор — перенос, а не удаление: в находке контекстуальная ценность, удалять её жалко.

**Ритм — по критической массе, а не по календарю** (`review_at: mass`): находка разбирается, когда материала набралось достаточно. На недельном срезе число в лотке — сигнал, а не норма.

**Ограничение — обезличивание.** Находка с работы на работодателя ложится в личный vault только обезличенной: класс явления, без имён, хостов и деталей конкретной системы.

**След:** обратная ссылка из черновика, как у образовательной заметки.

## Форма файла находки

Заводится шаблоном `80-kernel/templates/finding-tmpl.md`: спрашивает название, кладёт файл в лоток и ставит форму. Файл в лотке несёт минимальный frontmatter:

```yaml
---
type: finding
writer: mixed
aliases: ["человеческое название находки"]
created: ГГГГ-ММ-ДД
drafts: []
---
```

При переносе в `9-notes/` файл сохраняет frontmatter и получает в `drafts` ссылку на черновик.

## Подсчёт

**Правило `findings-tray`:** ожидаемый тип файла берётся из `item_type` карточки (здесь `finding`, оно же умолчание), подписи — «находка не разобрана». Неразобранные — все `.md`-файлы папки-носителя, кроме её `README.md`. Пустая папка — «лоток пуст». Старейшая находка — по `created`, при его отсутствии — по дате создания файла. Под числом — «разобрано: N»: страницы `home_after` с `type: finding` и ссылкой в `drafts`. Файл в лотке без `type: finding` всё равно считается, но отмечается строкой «без формы: N».

Находка, перенесённая в `9-notes/` без ссылки на черновик, на панели видна отдельной строкой «перенесено без черновика»: выход обязателен, и пропуск не должен выпадать из виду.
