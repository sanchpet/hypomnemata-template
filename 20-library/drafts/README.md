# 20-library/drafts — черновики

Черновик `d-NNN-<slug>.md`, `type: draft`, заводится `80-kernel/templates/draft-tmpl.md` (кнопка «Завести черновик» на стартовой). **Устремление обязательно** — без него не о чем писать; `projects` и `priority` — по выбору: приоритетные (1–3) назначаются на открытии юнита. Исчерпанный черновик — в `archive/`. Этот README панель черновиков не считает.
