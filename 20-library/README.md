# 20-library — письмо и источники (engineer-writer)

Здесь живёт мышление письмом: творческий конвейер **заметка → черновик → заготовка → текст** (INV-12), образовательные заметки по источникам (INV-13) и вечнозелёные тексты (INV-21). Writer — владелец (engineer-writer, INV-19); исключения объявлены во frontmatter (`writer: mixed`) — находки, выжимки бесед, таблицы прогресса карточек источников.

| Каталог | Что | Как появляется |
|---|---|---|
| `pipeline/entries/` | карточки **входов** конвейера (EN-N): где лежит вход, кто пишет, когда разобран, как считается | заводятся решением, по одной на вход |
| `pipeline/reasons/` | карточки **поводов письма** (WR-N): зачем пишется текст, с примерами | находятся сверкой с уже написанным |
| `pipeline/views/` | общий Dataview-модуль панели черновиков (`drafts-panel.js`) — один дом правила приоритета и массы черновика | код |
| `drafts/` | черновики `d-NNN-<slug>.md`: устремление обязательно, проекты и `priority` — по выбору на юните | `80-kernel/templates/draft-tmpl.md` |
| `posts/` | датированные тексты (`type: post`): не меняются после публикации | `text-tmpl.md` |
| `evergreen/` | вечнозелёные тексты (`type: evergreen`): растут редакциями | `text-tmpl.md` |
| `journal/` | дневник `ГГГГ/ММ-месяц/D-NNN-ДД-месяц-ГГГГ.md` | `daily-tmpl.md` |
| `resources/` | карточки источников и заметки по ним | шаблоны родов источников |
| `talks/` | доклады: материалы выступления в своей папке | вручную |
| `excalidraw/` | рисунки, не принадлежащие ни модели, ни источнику | Excalidraw |

**Модель конвейера целиком — на одной странице** [[creative-pipeline|«Модель творческого конвейера»]]: поводы, входы с живым счётом неразобранного, черновики по приоритету и массе, публикации и серия недель. Страница ничего не хранит — только показывает.

**Масса черновика** — сколько входов в него впало: входящие ссылки из учебных заметок, находок, бесед и дневника. **Приоритет черновика** — своё `priority: N` (набор юнита), иначе приоритет живого проекта из `projects`, иначе по массе.
