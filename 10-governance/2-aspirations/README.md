# 2-aspirations — устремления (ASP-N)

Второй ярус цепочки **направление → устремление → неудовлетворённость → проект → задача** ([[ADR-0035-aspiration-tier-and-chain|ADR-0035]]).

**Что это.** Устремление — к чему движение внутри направления. **Тест яруса: у устремления нет срока и нет критерия достижения.** Есть срок и критерий — это проект-цель, его место в `5-projects/` ([[ADR-0040-project-is-the-goal|ADR-0040]]). Устремления бессрочны и перечитываются раз в спринт.

**Видение живёт здесь** — полем `vision`, образом на горизонте одной-двумя фразами. `strategy.md` и `self-model.md` только индексируют его. Черновик образа, предложенный агентом, помечается `vision_status: draft` и остаётся видимо черновым, пока владелец не снимет пометку.

**Файл.** `ASP-N-<slug>.md`, скелет — `80-kernel/scaffolds/aspiration-tmpl.md`.

**Схема frontmatter:**

```yaml
---
type: aspiration
id: ASP-N
direction: "[[DIR-N-...]]"     # единственный родитель
vision: "<образ на горизонте>"
vision_status: draft           # опционально, только у черновика агента
aliases: ["<имя>", ASP-N]
valid_from: YYYY-MM-DD
---
```

**Поля состояния нет сознательно.** Неразведанность области — полноценная неудовлетворённость («область не разведана»), а не свойство карточки устремления.

**Проверка цепочки** — только вниз: устремление называет направление. Устремление без неудовлетворённостей — свидетельство покоя, а не разрыв. Проект без боли называет устремление напрямую полем `aspiration`.

**Откуда брать.** Устремление не сочиняется по образцу, а раскапывается по собственным прошлым решениям: карточки, проекты, записи сессий. Раскопанное проверяемо, сочинённое — нет.
