# 8-sessions — журнал дня

Одна запись на день: `YYYY-MM-DD.md`, скелет — `80-kernel/scaffolds/session-tmpl.md`. Открывает `/open`, наполняется по ходу работы, сводится на `/close`: сделанное, рубежи, capture-маршрутизация (INV-9), статус задач, рабочие продукты дня, план работ на завтра.

**Это первичное свидетельство о периоде** — своды недели, юнита и спринта строятся из записей сессий, а не из вывода `git` (FPF A.10). В день стратегирования сюда же владелец пишет сольный отчёт такта 2 (`80-kernel/docs/strategize-agenda.md`).

**Истина о предмете живёт в его карточке, а не в записи дня.** Запись дня — истина для своего дня; решение, осевшее только здесь, через неделю не найдётся. Решения уводятся в карточки, ADR, память — capture-разделом записи.
