# 1-directions — направления (DIR-N)

Старший ярус цепочки **направление → устремление → неудовлетворённость → проект → задача** (INV-14, [[ADR-0035-aspiration-tier-and-chain|ADR-0035]], [[ADR-0040-project-is-the-goal|ADR-0040]]).

**Что это.** Направление есть **разрез колеса баланса** — сектор жизни, а не звено цепи и не цель. Работа направления — показать, что ни один сектор не погас за период; порождает работу устремление, а не направление. Направлений немного (у автора — пять-семь), пересматриваются раз в спринт (шаг 4 `[S-план]` повестки).

**Файл.** `DIR-N-<slug>.md`, одна карточка на направление. Упразднённое — в `archive/` (создаётся при первом переносе), номер не переиспользуется.

**Схема frontmatter:**

```yaml
---
type: direction
id: DIR-N
aliases: [<человеческое имя>, DIR-N]
valid_from: YYYY-MM-DD
---
```

**Тело:** что входит в сектор и почему он отдельный; граница с соседним направлением (правило, читающееся в обе стороны); Dataview-вид устремлений направления.

**Проверка цепочки** — только вниз: направление никого не называет, устремление обязано назвать направление. Направление без устремлений — сектор, который сейчас ничего не требует, а не разрыв.

> Пример — [[DIR-1-example]]. Удалите его (и всю цепочку примеров `*-example`) после того, как заведёте свои карточки.
