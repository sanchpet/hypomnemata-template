# Стратегия

> **Пустой экземпляр** скелета `80-kernel/scaffolds/strategy-tmpl.md` ([[ADR-0016-strategy-document|ADR-0016]]). Скобки `{{...}}` заполняются на первой сессии стратегирования; дальше документ живой и правится в каждый день стратегирования.

> **Сквозной живой документ.** Один на всю систему. Отвечает: **зачем** развиваюсь (миссия), **каким стану** на длинном горизонте (видение), **как** двигаюсь (подход), **куда** в этом спринте и в этом году (цели), **где я сейчас** (состояние).
> **Owner (INV-2):** владеет миссией, видением, подходом, целями года и спринта, оценкой состояния. Направления и проекты владеют своим содержанием — здесь только **индексируются** (Dataview-вид, не копия). Журнал исполнения — НЕ здесь: спринт → `SprintReport`, юнит → `UnitReport`, неделя → `WeekReport` (все в `7-plans/archive/`), текущий план → `7-plans/current/`, сегодня → [[start|Старт]]. Карта цепочки → [[10-governance/index|Реестр]].
> **Жизненный цикл** (ADR-0037): просматривается и корректируется **в каждый день стратегирования**; на **закрытии юнита** — углублённый проход (сверка состояния); на **открытии спринта** — постановка трёх целей спринта и пересмотр видения; в **первую разгрузочную неделю года** — три цели года. Стабильность по слоям — это про *частоту правок* (миссия меняется редко, состояние — часто), а не про *запрет трогать*: трогать можно любой слой каждую сессию.

## Проекты-цели спринта — {{СПРИНТ, напр. 2027-s1 (W01–W12)}}

> Проект и есть цель ([[ADR-0040-project-is-the-goal|ADR-0040]]): результат, критерий, срок и бюджет живут в карточке проекта, здесь — только индекс (INV-2). Три проекта-цели **спринта** ставятся на открытии спринта (`period` спринта); в каждый день стратегирования корректируются по ходу (уточнение критерия, снятие/добавление по факту). Индекс намеренно не фильтруется по периоду: жёсткий фильтр опустошил бы раздел молча при открытии следующего спринта.

## Проекты (индекс)

> Родитель проекта — неудовлетворённость, либо устремление, где боли нет; направление читается подъёмом по цепочке. Пустой `period` значит, что проект не в фокусе спринта; бессрочное русло критерия не имеет. Разрез «с критерием / без критерия», он же список кандидатов на снятие, — в [[10-governance/index|Реестре]].

```dataview
TABLE WITHOUT ID link(file.link, file.aliases[0]) AS "Проект", default(dissatisfaction, aspiration) AS "Родитель", criterion AS "Критерий", period, status, scope
FROM "10-governance/5-projects" AND !"10-governance/5-projects/archive"
WHERE type = "project"
SORT period DESC, id ASC
```
