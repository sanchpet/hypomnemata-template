# 6-tasks — задачи (T-NNN)

Младший ярус цепочки **направление → устремление → неудовлетворённость → проект → задача** ([[ADR-0036-task-as-atomic-card|ADR-0036]]).

**Что это.** Задача — **действие внутри проекта, продвигающее его к выполнению**; атомарная self-contained карточка (ADR-0013): весь контекст в ней, без внешних указателей. Работы, на которые задача раскладывается, живут разделом «Работы» внутри карточки и уходят в прибор учёта заголовками `T-NNN — <формулировка>`, кратность 1:N.

**Метод — `80-kernel/docs/task-discipline.md`**: когда это задача, а когда строка чек-листа, повтор в приборе или проект; классы верификации; `awaiting`; зеркало в приборе. Скилл — `/task-new`, скелет — `80-kernel/scaffolds/task-tmpl.md`.

**Файл.** `T-NNN-<slug>.md`, номер — следующий свободный (уникальность проверяет `task-id-unique-check.py`). Закрытая — в `archive/` (создаётся при первом переносе).

**Ключевые поля** (полная схема с комментариями — в скелете):

- `project` — **единственный родитель**; остальная цепочка достаётся подъёмом.
- `role`, `method`, `budget_h` — назначаются при нарезке проекта; `budget_h` считается **во времени владельца**, а не в объёме работы.
- `artifact` — рабочий продукт, изменение в мире; **обязателен с момента `unit:`** — хук `check-task-artifact` краснеет без него.
- `unit: YYYY-wNN-wMM` — задача взята в юнит; ставится только на задачу проекта с `criterion`.
- `closed: YYYY-MM-DD` — обязателен при `done` · `closed` · `dropped` (хук `closed-date`).

**Не карточки:** намерения, не взятые в работу, живут строками в [[backlog]] с условием возврата событием; активация — заведение полной карточки.
