# 5-projects — проекты (PNN)

Четвёртый ярус цепочки **направление → устремление → неудовлетворённость → проект → задача**. **Проект и есть цель** ([[ADR-0040-project-is-the-goal|ADR-0040]]): отдельного реестра целей нет — `4-goals/` закрыт, и номер 4 оставлен в нумерации дырой как след эволюции.

**Два рода** (`scope`):

- `finite` — **проект-цель**: имя формулируется результатом, из которого цель видна без пояснений; есть наблюдаемый `criterion`, `period` (спринт, `YYYY-sN`) и `budget_h`. Завершается достижением критерия. Только такому проекту законно выделять время юнита — задача с `unit:` в проект без критерия краснеет в детекторе (ADR-0040 п.5).
- `infinite` — **русло**: держит постоянный род работы, критерия не имеет, завершаются отдельные задачи. Список проектов без критерия читается на шаге 4 сессии как **список кандидатов на снятие**.

**Родитель один:** `dissatisfaction` — где есть названная боль; `aspiration` — где боли нет, а есть стоячее намерение развиваться. Направление читается подъёмом по цепочке и полем не дублируется.

**Файл.** Проект — папка `PNN-<slug>/` с одноимённой карточкой `PNN-<slug>.md` внутри (ADR-0006); рядом в папке законно жить материалам проекта. Шаблон — `80-kernel/templates/project-tmpl.md` (кнопка «Завести проект» на стартовой). Завершённый — в `archive/`, номер не переиспользуется.

**Зеркало в приборе учёта** ([[ADR-0031-project-mirrored-in-time-tracker|ADR-0031]]): если ведётся прибор (у автора — Super Productivity), проект заводится и там, `PNN — <alias>`, иначе физическое время списывать некуда (INV-15). Номер назначает реестр, но перед выдачей сверяться и с прибором — карточка может лежать незакоммиченной на второй машине.

**Схема frontmatter:**

```yaml
---
type: project
id: PNN
dissatisfaction: "[[DIS-N-...]]"   # либо aspiration: "[[ASP-N-...]]" — где боли нет
period: YYYY-sN                     # finite: спринт, в котором проект взят
criterion: "<наблюдаемый критерий достижения>"   # finite
budget_h: 0                         # finite: время владельца на проект
scope: finite | infinite
status: active | incubation | done | archived | merged
priority: 1                         # ранг в очереди (1 — первый), ставится на стратегировании
investment: false                   # true — инвестиционный: горизонт 3–12 мес., 50–500 ч
priority_updated: YYYY-MM-DD        # когда ранг ставился; без даты устаревание невидимо
aliases: ["<имя-результат>", PNN]
valid_from: YYYY-MM-DD
---
```

**Тело:** к какому исходу ведёт и почему это проект, а не задача; критерий достижения чек-листом; Dataview-вид задач проекта; по мере жизни — таблица методов и строка конкуренции (повестка, шаг 4).
