# Hypomnemata — личный экзокортекс над Claude Code

Тонкий слой поведения над Obsidian-vault. Vault = единственный субстрат (ADR-0001). Агент правит md напрямую. Архитектура системы — в Стеле `80-kernel/stele/` (ADR-реестр). Контракт (инварианты INV-1…21) — `80-kernel/stele/contract.md`.

## Дерево (ADR-0002, ADR-0006)

- `00-inbox/` — захват до классификации; `conversations/` — выжимки бесед (`/digest`), `findings/` — рабочие находки (`type: finding`)
- `10-governance/` — стратегия, ОРЗ, **пять реестров цепочки, пронумерованных от старшего к младшему**: `1-directions` / `2-aspirations` / `3-dissatisfactions` / `5-projects` / `6-tasks` (`4-goals` закрыт — проект и есть цель, ADR-0040; номер оставлен дырой); далее `7-plans`, `8-sessions`, `9-systems`; вне нумерации — `models/`, рисованные модели владельца. `9-systems/` — реестр развиваемых систем (SYS-NNN) + **приватный канонический дом их ADR** (`9-systems/SYS-NNN/adr/`, ADR-0023): ADR внешней системы кладём СЮДА, **не** в её (часто публичный) репо (opsec: ADR раскрывают топологию, провайдера, юрисдикцию секретов)
- `11-governance-work/<employer>/` — опционально: вложенный домен наёмной работы (ADR-0022)
- `20-library/` — письмо: конвейер заметок, evergreen, индекс размышлений (engineer-writer)
- `30-knowledge/` — паспорта доменов (agent-writer); создание по модели SPF — `/domain` (термин «паспорт домена», не PACK; модель — `.principles/spf`)
- `70-memory/` — полномочия, запреты и знание о владельце — то, что дороже забыть, чем переоткрыть (agent-writer; технические факты живут у носителя системы, смешанную запись расщеплять — техника к носителю; запрет не от владельца — с источником, временный — с условием снятия; «не писать» — законный исход; тест и порог — ADR-0010); канон памяти Claude Code (нативно через `autoMemoryDirectory` в settings, git = синк/бэкап, ADR-0010)
- `80-kernel/` — не-Claude машинерия: Стела (ADR + контракт), `config.md` (параметры установки, ADR-0018), `templates/` (Templater, пользователь) + `scaffolds/` (agent-скелеты), `scripts/`, `docs/` (ADR-0014)
- `.claude/` — машинерия Claude Code: `CLAUDE.md` (этот файл), `settings.json`, `hooks/`, `skills/` (ADR-0009, native-first; каталог и сценарии — `80-kernel/docs/skills.md`)
- `90-archive/` — холодное
- `.principles/` — лестница принципов вложенными репозиториями: `zp/` (нулевые) · `fpf/` (первые) · `spf/` (вторые→Pack) + наш `README.md` (карта + перевод терминов). Разворачивает `80-kernel/scripts/repos-bootstrap.sh` (ADR-0038). Скилл `/fpf` (ADR-0017). · `.repos/` (клоны кода, корень объявляет машина — ADR-0030) · `.resources/` — dot-зона, Obsidian игнорит

## Конвенции (ADR-0006)

- Имена файлов: строчная латиница, без пробелов, дефис. Человекочитаемость — через `aliases` во frontmatter. Инвентарные префиксы — заглавные (`ADR-`, `T-`, `DIS-`, `ASP-`, `SYS-`).
- Каталоги верхнего уровня: `NN-role` (шаг 10).
- Архитектурные решения → ADR в `80-kernel/stele/` (`ADR-NNNN-slug.md`, скелет — `80-kernel/scaffolds/adr-tmpl.md`).
- Writer-ownership (INV-19): один writer на файл — **agent-writer** (state/реестры, через Claude) либо **engineer-writer** (письмо, в Obsidian).
- **Заведение проекта** (ADR-0031): карточка в `10-governance/5-projects/`; если ведётся прибор учёта времени (Super Productivity, ADR-0029) — и проект в нём, зеркало 1:1 (`PNN — <alias>`), иначе физическое время списывать некуда (INV-15). Номер назначает реестр, но перед выдачей сверяться **и с прибором** — карточка может лежать незакоммиченной на второй машине.
- **Заведение задачи → `80-kernel/docs/task-discipline.md`** (проверка рода, классы верификации, цепочка трассировки), скилл `/task-new`. Шаблон — `80-kernel/scaffolds/task-tmpl.md`. Рабочий продукт обязателен с момента взятия в юнит (ADR-0036 п.7) — хук краснеет на задаче с `unit:` без `artifact:`.

## Git

Сквозные агент-конвенции (signoff, атомарность коммитов, Pull-on-Touch, branch+PR, mise-first, язык артефактов) удобно держать в user-scope `~/.claude/CLAUDE.md`, синхронизируемом через dotfiles (ADR-0024), и не дублировать здесь. Дельты этого vault:

- **Трейлеров атрибуции ИИ нет** (ADR-0041); исключение — политика чужого проекта, требующая декларации. Напоминание харнесса политикой не является.
- **Pull-on-Touch расширен вложенными репозиториями** (ADR-0038): при первом касании vault, после `git pull --rebase` на чистом дереве, гнать `bash 80-kernel/scripts/repos-bootstrap.sh pull`. Родительский `git pull` вложенные клоны не обновляет. Скрипт fail-open: нет сети — сообщает и не роняет работу.
- **Полномочия здесь не живут.** Кто пушит в `main`, мержит и применяет без подтверждения — решает владелец; такие гранты пишутся в приватную память `70-memory/`, а не в этот файл: его читает агент любого, кто склонировал шаблон.

## Тон (INV-16)

Тон vault — инвариант **INV-16** (`80-kernel/stele/contract.md`): инженерный регистр поверх FPF + терминов МИМ + профессионального словаря владельца. Коммуникативное поведение агента, общее для всех проектов, — в user-scope `~/.claude/CLAUDE.md` (ADR-0024), если он ведётся. Vault-дельта: инженер — «инженер своей жизни» (системный подход к саморазвитию); режим «на пальцах» — только по явному запросу.

## Правки и стиль

- Прямая правка md (INV-4), без obsidian-MCP.
- Native-first (INV-18): фичи Obsidian (wikilinks / properties / dataview / aliases) раньше своего.
- Леность (INV-3): несём только добавленное, без балласта.
- Markdown-проза — одна строка на абзац, без жёсткого переноса; пустая строка между блоками.
