# ADI-цикл рассуждения

> FPF B.5 (ADI). Доверие к данным: F-G-R (B.3) — факт / предположение / слух. Сравнение вариантов: A.19 — одинаковые критерии для всех. Принципы — в `.principles/fpf` (при нужде — через `/fpf`).

Задача: $ARGUMENTS

## 1. Abduction — гипотезы

Сгенерируй 2-3 РАЗНЫХ гипотезы решения. Не останавливайся на первой идее.

## 2. Deduction — логика

Для каждой гипотезы: внутренняя непротиворечивость, соответствие ограничениям, потенциальные проблемы.

## 3. Induction — evidence

Подтверждения/опровержения в материале: vault (заметки, ADR, паспорта `30-knowledge`), код, источники (`resources-tracker` / `.principles`). Помечай уровень доверия F-G-R: факт / предположение / слух.

## 4. Audit — проверка на bias

Не якорюсь ли на первой гипотезе? Не игнорирую ли контр-evidence? Достаточно ли разнообразны гипотезы?

## 5. Decide — выбор и обоснование

Лучшая гипотеза (сравнение по A.19 — одинаковые критерии), rationale выбора, остаточная неопределённость и риски.

**Выход:** структурированный анализ + финальная рекомендация. Архитектурное решение → дальше `/archgate`.
