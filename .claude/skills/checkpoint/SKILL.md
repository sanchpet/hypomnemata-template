# /checkpoint — Закрытие сессии (Quick Close, INV-9 масштаб «сессия»)

Самый частый масштаб ОРЗ: закрыть рабочую сессию внутри дня, ничего не потеряв. Открытие сессии = Гейт задачи (`80-kernel/docs/task-discipline.md` — любое задание → проверка/заведение задачи).

1. **Коммит** — `git status` по vault → незакоммиченное → `git add <конкретные пути>` → commit (+ push, если ваш vault пушится без подтверждения). Не потерять.
2. **Capture** — появилось знание за сессию? Маршрутизировать (как /close): архитектура → ADR `80-kernel/stele/`; **память (`70-memory/`) — только то, что дороже забыть, чем переоткрыть**: выданное полномочие (забуду — переспрошу разрешённое), запрет (забуду — сделаю разрушительное), знание о владельце и о работе с ним. Технический факт о системе или инструменте (забуду — потеряю время) → к носителю системы: `10-governance/9-systems/SYS-NNN/`, паспорт домена в `30-knowledge/`, `references/` скилла; но факт, незнание которого разрушительно, — в память как запрет; запрет или полномочие не от владельца — тоже, с названным источником; временное — с датой и условием снятия; смешанную запись расщепить; не нужно ни памяти, ни носителю — не писать. Тест и порог выбытия — [[ADR-0010-memory-in-repo-native-config|ADR-0010]]; доменное → `30-knowledge/`; семя письма → `20-library/`. Нет нового → пропустить молча.
3. **Handoff** — активная задача: обновить в карточке раздел «Осталось» (следующий шаг + контекст для следующей сессии).

Сессия ≠ день: `/close` самодостаточен — `/checkpoint` внутри него не повторять. Пропуск сессии не детектируется (масштаб текучий) — это гигиена «не потерять», коммит ловит главное.
