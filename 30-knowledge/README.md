# 30-knowledge — паспорта доменов (agent-writer)

Формализованное знание о предметных областях, в которых владелец действует: **паспорт домена** по модели SPF (`.principles/spf`), а не свободные заметки (INV-20). Паспорт создаётся и ведётся агентом — скилл `/domain`; владелец ратифицирует. Термин — «паспорт домена», не PACK.

**Раскладка:** `30-knowledge/<домен>/` — паспорт домена и его карточки (каталог с `README.md`-перечнем), либо один файл `30-knowledge/<домен>.md`, пока домен мал.

**Что сюда не кладётся:**

- технические факты эксплуатации конкретной системы — к носителю системы, `10-governance/9-systems/SYS-NNN-*/operations-notes.md`;
- знание о владельце, полномочия и запреты — в `70-memory/` (ADR-0010);
- письмо и размышления — в `20-library/` (engineer-writer).

**Опционально — ядро знаний** `30-knowledge/core/`: вложенный репозиторий обезличенного знания, общего для личного и рабочего экзокортексов (ADR-0027, ADR-0038). Нужен, только если экзокортексов два.

Уже здесь: `systems-thinking/new-practice-learning-meta-model.md` — мета-модель освоения практики саморазвития, шаблон карточки практики (на него указывает `80-kernel/scaffolds/practice-tmpl.md`).
