# 00-inbox — захват до классификации

Сюда падает всё, чему ещё не присвоен род: мысль, ссылка, задача-кандидат, находка. Разбор — по методу `80-kernel/docs/inbox-triage.md`: днём на `/open` (режим light), в день стратегирования (режим strict, «провисело >7 дней нерешённым → архив»). **Род и адрес записи назначает владелец**; агент готовит разбор и предъявляет вопросом.

Три лотка здесь принадлежат творческому конвейеру и живут по своим правилам (карточки входов — `20-library/pipeline/entries/`):

- `fleeting-notes.md` — мимолётные заметки, одна запись — один пункт списка с датой (вход EN-1);
- `findings/` — рабочие находки, файл на находку, `type: finding` (вход EN-4, шаблон `80-kernel/templates/finding-tmpl.md`);
- `conversations/` — выжимки бесед с агентом, `type: conversation` (вход EN-5, скилл `/digest`).

Находки и беседы разбираются **по массе**, а не по неделе, и уходят переносом в `20-library/resources/9-notes/` со ссылкой на черновик, а не в архив.
