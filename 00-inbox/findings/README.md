# 00-inbox/findings — лоток рабочих находок

Мысль, рождённая делом, а не чтением: файл на находку, `type: finding`, `writer: mixed` (INV-19). Заводится шаблоном `80-kernel/templates/finding-tmpl.md`. Разбор — по массе: файл переносится в `20-library/resources/9-notes/` и получает в `drafts` ссылку на черновик. Находка с работы на работодателя ложится сюда только обезличенной: класс явления, без имён, хостов и деталей системы. Правила — карточка входа [[en-4-work-findings|EN-4]]. Этот README в счёт лотка не входит.
