# Память

> Память несёт только то, что дороже забыть, чем переоткрыть: полномочия, запреты, знание о владельце. Технические факты — у носителя системы (маршрутизатор внизу); смешанную запись расщеплять: техника — к носителю. Запрет не от владельца — с источником, временный — с условием снятия; «не писать» — законный исход. Порог: ≤60 записей, ≤8 700 символов индекса (≈12 КБ; меряет `orz-check.sh`) — превышение = ревизия на стратегировании (ADR-0010). Хук есть текст ссылки; родственное — через `·`.
>
