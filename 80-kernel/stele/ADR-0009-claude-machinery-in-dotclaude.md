# ADR-0009 — Вся машинерия Claude Code (включая CLAUDE.md) в `.claude/`

## Контекст

Контракт ([[ADR-0002-topology-mono-kernel|ADR-0002]]) кладёт машинерию в `80-kernel/`. Claude Code грузит `CLAUDE.md` из нескольких документированных мест, включая **`./.claude/CLAUDE.md`**, и читает конфиг/хуки из `.claude/`. Вопрос: где единый дом Claude-конфига?

## Решение

**Вся машинерия Claude Code — в `.claude/`:** `.claude/CLAUDE.md` (ориентация, документированная локация) + `.claude/settings.json` (permissions, регистрация хуков) + `.claude/hooks/` (тела хуков) + `.claude/scripts/` / `skills/` / `commands/` по мере появления. CLAUDE.md перенесён из корня сюда — единый дом, без исключений. И точка входа, и хуки ищутся Claude Code здесь — native-first (INV-18) и наименьшее удивление (разработчик ищет хуки в `.claude/hooks`, не в kernel). `80-kernel/` держит **НЕ-Claude машинерию**: Стелу (ADR), шаблоны Templater (Obsidian), автономные скрипты/glue.

Уточняет ADR-0002: пункт «kernel держит `.claude`/хуки» заменён — Claude-машинерия уходит в нативный корневой `.claude/`, в `80-kernel` остаётся не-агентская часть.

## Альтернативы

- **Тела хуков в `80-kernel/hooks/`, в `.claude` только регистрация** — отклонён (1-я редакция этого ADR, исправлено по замечанию инженера): непоследовательно с native-first, которым обоснован сам корневой `.claude`; разработчик ищет хуки в `.claude/hooks`, а не в kernel — нарушение наименьшего удивления.
- **`.claude` в `80-kernel/` + симлинк из корня** — отклонён: симлинки хрупки кросс-платформенно (Windows), лишняя индирекция против INV-18.
- **cwd = `80-kernel/`** — отклонён: работаешь в корне vault (там заметки), cwd не сдвинуть.

## Последствия

- + Вся Claude-машинерия (CLAUDE.md, хуки, скрипты, скиллы) — в нативном `.claude/`, единый дом, без исключений; корень vault чище (`start.md` + `NN-`каталоги).
- ⚠ verify: подтвердить в vault-сессии, что `CLAUDE.md` грузится из `.claude/CLAUDE.md` (как память — проверкой).
- − Машинерия в двух местах: `.claude/` (Claude Code) + `80-kernel/` (Стела, шаблоны, прочее). Граница по принципу «чья конвенция владеет»: Claude Code → `.claude`, всё остальное → `80-kernel`.
