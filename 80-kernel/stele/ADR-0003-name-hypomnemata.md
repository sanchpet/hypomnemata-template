# ADR-0003 — Имя системы: Hypomnemata

> Заметка шаблона: имя — выбор автора, а не часть устройства. При форке меняйте его свободно; ADR остаётся образцом того, как имя связывается с функцией системы.

## Контекст

Имя личной системы. Перебор из нескольких культурных источников (литература, античность, кино) → шорт-лист → финал после проверки коллизий.

## Решение

**`Hypomnemata`** (ὑπομνήματα, фукольдианская множественная форма — «L'écriture de soi», 1983). Расслоение числа: система = `Hypomnemata` (собрание); одна запись = `hypomnema`; `anamnesis` (платоново «device of artificial memory») зарезервирован под recall-слой / стартовую проекцию (INV-11). Repo `hypomnemata`, CLI `mnema`.

## Альтернативы

- **Кандидаты шорт-листа** (Waldzell, Castalia, Lambda, Engram и др.) — отклонены по коллизиям: активные компании и OSS-проекты в том же поле (ИИ-память, MCP), перегруженные термины, имена, тонущие в топонимах.

## Последствия

- + Чистая коллизия; имя = функция (hypomnemata = «material memory … for rereading and meditation»).
- + Guardrail анти-`pharmakon` (Платон, «Федр» 274c–275b): система — инструмент ассимиляции, не склад → держит экзоскелет ≠ автопилот и Заметка (видимое) ≠ Нейронные связи.
- − Форма длиннее в наборе — снято CLI-алиасом `mnema` (у автора — в dotfiles; шаблон его не ставит).
