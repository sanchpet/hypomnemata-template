# ADR-0024 — Глобальные агент-конвенции в `~/.claude/CLAUDE.md` (dotfiles); ~~атрибуция = `Assisted-By`~~

## Контекст

`CLAUDE.md` живёт в каждом проекте (ADR-0009 — Claude-машинерия в `.claude/`). Но **сквозные** правила агента (signoff, trailer соавторства, branch+PR, атомарность, Pull-on-Touch, mise-first, English-артефакты) оказались **скопированы в десяток с лишним project-`CLAUDE.md`** и частью в память. Это балласт (INV-2/INV-3), и он уже дал дрейф: trailer встречался в нескольких несовместимых формах.

Два структурных пробела: (1) project-`CLAUDE.md` грузится, только когда cwd в этом проекте; vault-память (`70-memory/`, ADR-0010) — только когда сессия включает vault. **Не было дома для «применяется в КАЖДОЙ сессии, в т.ч. вне vault»** (голый рабочий или чужой репо). Claude Code нативно грузит **user-scope `~/.claude/CLAUDE.md`** во всех сессиях. (2) Заодно назрел вопрос семантики trailer: `Co-Authored-By: Claude` заявляет **со-авторство**, тогда как правку авторит владелец, а Claude ассистирует.

## Решение

1. **User-scope `~/.claude/CLAUDE.md` — единый дом сквозных, несенситивных агент-конвенций.** Исходник — в **публичном** dotfiles-репо (у автора — под chezmoi), раскладывается менеджером dotfiles. Грузится в каждой сессии (native-first, INV-18). **Precedence:** global — база, project-`CLAUDE.md` уточняет или переопределяет. Расширяет ADR-0009 (добавляет user-scope слой к `.claude`-машинерии).
2. **Граница трёх уровней (opsec, ADR-0023).** Global (публичный dotfiles) = универсальное + **публично-безопасное**; vault `.claude/CLAUDE.md` = специфика hypomnemata; vault `70-memory/` = приватно-личное. Приватная деталь (почты, хосты работодателя, модель угроз) в публичный global **никогда**.
3. ~~**Атрибуция = `Assisted-By: Claude <noreply@anthropic.com>`** на агент-коммитах (не `Co-Authored-By`); на корп-хостах — trailer не ставим вовсе.~~ — **отменён [[ADR-0041-no-ai-attribution-trailer|ADR-0041]]**: трейлеров атрибуции ИИ нет ни в одном репозитории. Прочие решения этого ADR в силе.

## Альтернативы

- **Оставить дубли по проектам** — отклонён: балласт (INV-2/3) и уже наступивший дрейф форм trailer.
- **Универсальные правила в vault-память (`70-memory/`)** — отклонён: память грузится только в vault-сессии, не покрывает работу вне vault; и она приватна — не может быть публичным и переносимым домом.
- ~~**Оставить `Co-Authored-By`** — отклонён: заявляет joint authorship.~~ — вопрос trailer снят целиком ADR-0041.

## Последствия

- + Один дом сквозных конвенций; конец копипасте (INV-2/3); применяется везде, включая вне vault; нативно (INV-18).
- − Global в **публичном** репо → постоянная дисциплина держать его публично-безопасным (opsec, ADR-0023).
- − Хвост раскатки: project-`CLAUDE.md` какое-то время несут дубли; дедуп идёт инкрементно при следующем касании каждого репо, не big-bang.
- − Машинерия теперь в трёх loading-scope (global user / project / vault-память); граница задана п.2.
