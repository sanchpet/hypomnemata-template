# ADR-0008 — Раскладка Obsidian: снимок Workspaces, не живой workspace.json

> Заметка шаблона: сам снимок `.obsidian/workspaces.json` в шаблон не везётся — это раскладка панелей автора. Соберите свою раскладку, сохраните её снимком (core-плагин Workspaces) и закоммитьте `workspaces.json`; живой `workspace.json` остаётся в `.gitignore`.

## Контекст

Хочется, чтобы раскладка панелей (правый сайдбар и пр.) переносилась между устройствами (INV-1). Живой `.obsidian/workspace.json` для этого плох: переписывается каждую сессию (churn) и при работе с нескольких машин даёт merge-конфликты на машинном JSON — тот же класс боли, что конфликт-копии облачных дисков.

## Решение

Живой `workspace.json` — **gitignored** (локальное UI-состояние). Переносимую раскладку держим через core-плагин **Workspaces**: именованный снимок пишется в стабильный `.obsidian/workspaces.json`, который меняется только по явному «Save layout». Его **коммитим** — едет на все устройства без churn и конфликтов.

## Альтернативы

- **Коммитить живой `workspace.json`** — отклонён: churn в каждом коммите + мульти-девайс merge-конфликты на машинном JSON.
- **`workspace.json` + `git update-index --skip-worktree`** — отклонён: прячет churn, но Obsidian переписывает файл локально → `git pull` с upstream-изменениями упирается в «local changes would be overwritten»; флаг локальный, надо re-apply на каждом клоне.
- **Gitignore + ручной re-seed** — отклонён: раскладка не едет, теряется на новом устройстве.

## Последствия

- + Раскладка едет в git стабильным снимком (INV-1), без churn (INV-3), без конфликтов.
- − Раскладку надо явно пересохранять снимком после изменений (не авто).
- Операционно: на новом устройстве — загрузить снимок (или назначить стартовым).
