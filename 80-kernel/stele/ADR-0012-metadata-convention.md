# ADR-0012 — Конвенция метаданных (свойства + теги)

## Контекст

Метаданные vault: **свойства** (frontmatter), **теги**, **имена файлов**. Имена закрыты [[ADR-0006-naming-convention|ADR-0006]]. Здесь — свойства и теги: на них держатся Dataview-витрины (стартовая страница, индексы), триаж, будущие Bases. История: сперва ключи были кириллические (`тип`/`статус`) и разъехались с governance; Ф3 унифицировал ключи на английские, но оставил значения двуязычными (`в-работе` vs `in-progress`) — это породило путаницу. Финальное решение Ф3: **вся метадата английская**.

## Решение

**Свойства (ключи + значения) — английские. Теги и контент — ru-first.**

- **Граница:** свойства (`type`/`status`/…) = формальная схема + коды/enum, обращены к Dataview / Bases / скриптам / агенту → английские (нативные ключи `aliases`/`tags` и так английские; значение-классификатор = код, а не контент). Теги и контент = смысл → ru-first: язык понятия. Английский снимает двуязычную путаницу в схеме; ru-first живёт в **смысле** — тело заметки, заголовок через `aliases`, **теги-понятия**. Как имена файлов (ASCII-структура, русский в `aliases`).
- **Почему не «значения ru-first»** (отклонено): значение-классификатор — это код enum, а не контент. `в-работе`/`in-progress` для одного состояния = путаница; один код = одно имя (OwnerIntegrity на уровне схемы).

### Ось 1 — Свойства (YAML frontmatter, одно значение из набора)

| Поле | Значения (по роду сущности) | Назначение |
|------|----------|-----------|
| `type` | документы: `learn-note` · `note` · `journal` · `quote` · `system`; ресурсы: `book` · `course` · `guide` · `source`; сущности: `task` (в первой редакции `work-product`) · `project` · `direction` · `dissatisfaction` · `adr` | вид документа/сущности |
| `status` | контент: `later` · `in-progress` · `processed` · `incubating` · `done`; задача: `in-progress` · `blocked` · `done` · `later` · `closed` · `dropped`; ADR: `proposed` · `accepted` · `superseded` · `withdrawn` | жизненный цикл (scoped по роду) |
| `channel` | `<channel-1>` · `<channel-2>` · … — перечень каналов публикации ваш | канал публикации поста |

**Правила:**

- Ключи и значения — английские; single-value; значения kebab-case без пробелов.
- Метаданные — в **YAML frontmatter** (Properties / Bases видят), не в inline `key:: value`.
- Витрины/триаж: `WHERE type = "book" AND status = "in-progress"`.
- `status` scoped по роду (`type`): один код, одно значение, без RU-дублей.
- **`later` — единый код «отложено / не сейчас»** для контента И задач (унифицировано 2026-06-27; ранее задачи использовали `defer` — два слова под один смысл расклеивали логику без выгоды). `blocked` (внешне заблокирован), `closed` (свёрнут) и `dropped` (снят, [[ADR-0036-task-as-atomic-card|ADR-0036]]) остаются специфичными для задач — это иные состояния, не «отложено».
- ⚙️ **Поправка 2026-10-05: `closed: YYYY-MM-DD` — дата закрытия задачи и проекта.** Обязательна, когда `status` становится терминальным (задача: `done` · `closed` · `dropped`; проект сверх того `archived` · `merged`); не из будущего и не раньше `opened:`. Без даты свод периода не знает, в какой период легло закрытие. Принуждается pre-commit-хуком `closed-date` (`80-kernel/scripts/closed-date-check.py`).
- **Ресурсы** (источники саморазвития, [[ADR-0015-resource-tracker|ADR-0015]]): источник верхнего уровня — `id: R-NNN` + имя `R-NNN-slug.md`; даты — `started` / `completed` (не в имени). `book`/`course`/`guide` конечны (имеют `completed`); `source` (сообщества, блоги, программы) вечен — `status: active`, без `completed`. Под-материалы (главы/конспекты) своего R не имеют, ссылаются на R родителя.

Энфорсмент схемы `status` — pre-commit-гейт `frontmatter-check` ([[ADR-0019-pre-commit-framework|ADR-0019]]); `channel` гейтом не проверяется.

### Ось 2 — Теги (ru-first, семантика контента)

Тег — **не** метадата-код, а семантика контента: навигация по понятиям, читается человеком в графе/тег-пейне как личный словарь мышления. Поэтому **ru-first**: русское понятие — русским тегом (`#философия` · `#мим` · `#ии`); английский — только там, где код или имя собственное (`#k8s` · `#devops`). Это и есть граница со свойствами: `type`/`status` = формальная схема (английская), тег = смысл (язык понятия). Плоско, lowercase, не вкладывать. Функциональный маркер `#фокус` (переключатель стартовой страницы). Не дублировать оси-свойства тегами (нет `#book`/`#in-progress` — это `type`/`status`).

### Ось 3 — Имена файлов

Закрыто [[ADR-0006-naming-convention|ADR-0006]]: английский slug + русский заголовок в `aliases`; инвентарные префиксы заглавными (`T-001-`, `ADR-0012-`).

## Последствия

- + Однородная схема и значения: ни одного RU-дубля английского кода; Dataview/Bases/скрипты/агент читают единый словарь. Путаница `в-работе`↔`in-progress` снята.
- + ru-first сохранён в смысле (тело заметки, заголовок через `aliases`, теги-понятия) — где он и нужен; формальная схема (свойства) английская.
- − Русский заголовок виден только через `aliases`/тело, не во frontmatter-значениях (приемлемо — это машинный слой).

## Источник

Документ-соглашение по именованию из предыдущего vault. При Ф2 перенесён, при Ф3 метадата унифицирована на английскую (ключи + значения).
