# ADR-0021 — Решённые неудовлетворённости → подкаталог `archive/` (сохранение wikilinks)

## Контекст

Решённые неудовлетворённости первоначально сворачивались в таблицу `resolved.md`, а файлы DIS удалялись (конвенция «отдельными заметками не держим»). Но проекты и задачи ссылаются на свои драйверы через wikilinks `[[DIS-N-slug]]`; удаление файла **рвёт ссылку** (dangling), теряется обоснование цепочки (INV-17) и нативная связность (INV-18). Записи, заведённые до введения правила без отдельных файлов, существуют только строкой таблицы.

## Решение

- Решённые DIS, **у которых есть файл**, переезжают в `10-governance/3-dissatisfactions/archive/` со `status: resolved` + `resolved: YYYY-MM-DD` + строкой «Решено: как». Файл сохраняется → wikilinks из проектов и задач **резолвятся**.
- Активные DIS остаются в корне `3-dissatisfactions/`. Dataview активного списка фильтрует по `status = "active"` — архив выпадает сам (подпапка сканируется, но отсечена статусом).
- `resolved.md` → реестр записей до введения правила (без файлов) + Dataview-индекс архива.
- Симметрично `7-plans/` (`current/` + `archive/`).

## Последствия

- **+** Wikilinks из проектов и задач на закрытые драйверы не висят (INV-18); цепочка трассировки читается исторически (INV-17).
- **+** Нативно (Obsidian-папка + статус), без своей машинерии.
- **−** Лёгкая двойственность: ранние записи (таблица) vs поздние (файлы) — оправдано, у ранних файлов нет. В свежем vault двойственности нет: таблица пуста, сразу работают файлы.
- Заменяет в `resolved.md` стереотип «отдельными заметками не держим».
