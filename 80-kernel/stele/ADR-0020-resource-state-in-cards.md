# ADR-0020 — Состояние источника живёт в его карточке (трекер = тонкая витрина)

Уточняет [[ADR-0015-resource-tracker|ADR-0015]] (трекер источников + политика слотов): меняет **где живёт состояние**, политику слотов не трогает.

## Контекст

`resources-tracker.md` держал одновременно верхнеуровневое (Dataview-витрина, стандартный бюджет на раздел, недельный кросс-журнал, критерии качества) **и** per-source детали (таблица разделов руководства, расписание и прогресс курса, описания отдельных источников, архив завершённых). Карточки источников (`20-library/resources/**`) при этом тонкие. Состояние источника **размазано** между трекером и карточкой → дубль и split-brain, нарушение OwnerIntegrity. Это тот же изъян, что governance уже вылечил для задач ([[ADR-0013-wp-card-self-contained|ADR-0013]]: карточка владеет статусом, вид агрегирует Dataview).

## Решение

- **Карточка источника — единственный владелец своего состояния:** темы, прогресс по разделам, расписание занятий, метаданные источника живут в карточке (`20-library/resources/**`, поле `id: R-NNN`). Карточка самодостаточна и переносима (INV-1).
- **`resources-tracker.md` → тонкий верхнеуровневый индекс:** Dataview-витрина над карточками + только **кросс-источниковое/методное** — стандартный бюджет на раздел, недельный кросс-журнал прохождения (одна строка на сессию, по всем источникам), критерии качества. Per-source блоки удалены (мигрированы в карточки).
- **Потребители обновлены:** `/open` читает тонкий трекер (витрину) + при необходимости карточку источника дня; `/strategize` (актуализация материалов) — витрину + кросс-журнал, детали в карточках.
- Зеркалит паттерн ADR-0013 на подсистему источников.

## Альтернативы

Профиль ЭМОГССБ (ArchGate, критические — Эволюционируемость + Генеративность):

| χ | Status quo | **Гибрид (принят)** | Радикальный (без трекера) |
|---|-----------|---------------------|---------------------------|
| Эволюц. ⭐ | ⚠️ дубль | ✅ | ⚠️ теряет кросс-вид |
| Генерат. ⭐ | ⚠️ балласт | ✅ | ✅ |
| Обучаем. | ✅ | ✅ | ⚠️ нет витрины на /strategize |

- **Status quo** — отклонён: дубль трекер↔карточка (INV-3), split-brain состояния.
- **Радикальный** (всё в карточки, трекера нет) — отклонён: теряется кросс-источниковый недельный журнал и единый обзор на стратегировании.
- Профиль гибрида чистый (7×✅), оба критических ✅, ⚠️ нет → прошёл вето-фильтр.

## Последствия

- **+** OwnerIntegrity: одно состояние, один владелец (карточка). Снят дубль (INV-3).
- **+** Карточки самодостаточны/переносимы (INV-1); добавить источник = добавить карточку, трекер не пухнет (масштабируемость).
- **+** Консистентность с governance (ADR-0013) — одна ментальная модель «карточка-владелец + витрина».
- **−** Разовая миграция: несколько карточек + переписать трекер + синхронно обновить `/open` и `/strategize` (иначе split-brain в скиллах).
- **−** Источник без карточки (пред-отобранный, ещё не начатый) stub-блоком не мигрирует — заводится карточкой на `/strategize` при старте.
