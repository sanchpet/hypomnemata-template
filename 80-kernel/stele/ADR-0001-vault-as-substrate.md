# ADR-0001 — vault-as-substrate

## Контекст

Нужен личный лёгкий слой над Claude Code. Издержки апстрима IWE: кривое обновление с переписыванием личных файлов, нет переносимости, синк памяти — «адская боль», тысячи опций `params.yaml`, 320-файловый рантайм. Ключевой инсайт: автор апстрим-шаблона IWE написал не рантайм, а конфиг-слой над Claude Code — значит «своё» = свой тонкий слой над теми же примитивами, не платформа.

## Решение

**Obsidian vault = единственный субстрат**, система = тонкий слой поведения над md-файлами. Агент правит md напрямую (минус obsidian-MCP-индирекция), Properties/Dataview из коробки. Апстрим IWE = pull-by-need референс, не poll. Не форк, не дистрибутив — чистая личная пересборка (Готовая техника ≠ Готовый продукт-рантайм).

## Альтернативы

- **B: retrofit шаблона IWE** — отклонён. Сохраняет 320-файловый рантайм + `update.sh` → каскад при изменении и `params.yaml`-балласт против Context Engineering SOTA. Профиль ЭМОГССБ: 5⚠ против 1⚠ у A; обе критические (Эволюционируемость, Современность) у A — ✅.

## Последствия

- + Low lock-in, прямая правка md, переносимость (чистый клон vault = система).
- − Генеративность ⚠ — принята **by design**: anti-scope «не платформа, n=1».
- − Единственный мейнтейнер без апстрим-фиксов — митигируется крошечной поверхностью (INV-7).
