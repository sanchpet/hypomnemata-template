# Триаж инбокса (метод)

> Единственный владелец процедуры разбора `00-inbox/` (INV-2). Вызывается в двух каденциях: `/open` (день, режим **light**) и `/strategize`, шаг «Триаж» повестки (день стратегирования, режим **strict**). День и неделя — не два метода, а один в двух режимах. Запись инбокса — *кандидат* (pre-work), у которого ещё не присвоен род; триаж = присвоить род и увести по адресу.

## Карта родов → куда

| Род записи | Куда |
|------------|------|
| **Неудовлетворённость** (что не так, хочу иначе) | `10-governance/3-dissatisfactions/DIS-N-*` — сначала проверить выход на устремление (иначе не неудовлетворённость, а каприз) |
| **Задача проекта** (действие, продвигающее живой проект) | активно сейчас → карточка по `task-discipline.md` (`scaffolds/task-tmpl`); не сейчас → строка в `6-tasks/backlog.md` |
| **Мелочь вне проектов** (две минуты, ни к чему не привязана) | сделать сразу или короткой заметкой; карточку не заводить |
| **Знание доменное** | `30-knowledge/<домен>/` |
| **Знание реализационное / техническое** | `80-kernel/docs/` или заметки у носителя системы (`9-systems/SYS-NNN/`) |
| **Архитектурное решение** | ADR в `80-kernel/stele/` (`scaffolds/adr-tmpl`) |
| **Семя письма / черновик** | `20-library/` |
| **Шум** | удалить; при сомнении → `90-archive/` |

## Кто присваивает род

**Род и адрес записи назначает владелец. Агент готовит разбор и предъявляет его вопросом — переносить, удалять и архивировать сам не вправе.**

Запись захвата есть сырьё чужого мышления: род известен тому, кто её сделал, а не тому, кто её читает. Строгий режим вдобавок несёт форсирующую функцию «>7 дней → архив», то есть право уничтожать внимание владельца по таймеру. У автора метод поначалу описывал процедуру, не называя исполнителя, и несколько проходов подряд агент вёл сам — пока владелец это не остановил.

Форма предъявления: таблица «запись → предполагаемый род → адрес → основание», ратификация построчно. Неочевидное сопровождается вопросом о недостающем свидетельстве, а не догадкой.

## Два склада, две секции

Триаж может покрывать **не только** `00-inbox/`: в него законно вливаются внешние копилки захвата — «Избранное» мессенджера, личный канал-копилка, заметки телефона. Хранилище есть деталь; род работы один и тот же.

Но поток и запас мерить порознь, иначе процедура теряет собственный индикатор здоровья:

| Секция | Что | Правило |
|---|---|---|
| **Поток** | свежий захват (`00-inbox/`, новое во внешних копилках) | разбирается **весь**; строгий режим применяет «>7 дней → архив» |
| **Запас** | накопленная копилка (сотни записей за годы) | разбирается **квотой**; единица — **тема**, не запись; ведётся знаменатель |

> ⛔ **Строгое правило `>7 дней → архив` на запас не переносится.** Оно писалось против залежавшегося свежего захвата; применённое к многолетнему складу, оно стёрло бы всё на первом же проходе. Запас живёт по образцу «квота за заход плюс знаменатель».

## Режимы

**light (день, `/open`).** Присвоить род свежим записям, увести по адресу. Неопределённое — **оставить** в `00-inbox/` (ещё исследуем). Цель — не дать свежему накопиться.

**strict (день стратегирования, `/strategize`).** Тот же проход + **форсирующая функция:** запись, провисевшая в `00-inbox/` **>7 дней** нерешённой → `90-archive/`. **Не жалей** — если за неделю триажа род так и не присвоен, ценность записи не подтверждена. Архив обратим (холод, не удаление), но из активного внимания уходит.

⚙️ **Кроме лотков творческого конвейера** — `00-inbox/findings/`, `00-inbox/conversations/` и `00-inbox/fleeting-notes.md`: у них свой ритм разбора (по массе либо на блоке «Творческий конвейер» повестки) и свой исход — перенос в черновик или в `9-notes/`, а не архив. Правила — в карточках входов `20-library/pipeline/entries/`.

## Зачем strict (FPF-обоснование)

- **Explore-exploit с тайм-боксом (C.19):** неделя = окно исследования; дальше commit-or-abandon, устойчиво к sunk-cost.
- **Лимит WIP (Inventory ≠ Progress):** нерешённая запись = замороженный капитал, тянет внимание. Без форса инбокс растёт как инвентарь.
- **Присвоение рода (Проблема ≠ Задача ≠ ФР ≠ Работа):** strict заставляет назвать род или признать, что его нет (шум → архив).

Окно «7 дней» — параметр (привязан к недельному проходу: пережил полную неделю нерешённым → архив).
