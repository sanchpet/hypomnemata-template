# Учёт прогресса освоения источников

Как агент ведёт прогресс по протяжённому источнику — курсу, книге, руководству. Карточки источников лежат в `20-library/resources/**`; настоящий документ задаёт только правило ведения их таблицы «Прогресс».

### Прогресс — дробью против полного объёма источника

При освоении любого протяжённого источника (курс, книга, руководство) **отмечать фактическое прохождение плана прямо в сессии** и отражать его в таблице «Прогресс» карточки источника (`20-library/resources/**`) — **против общего объёма источника** (N разделов/глав/модулей), чтобы прогресс читался дробью (напр. «2/9 разделов»), а не размытым `in-progress`.

**Почему:** без фиксации фактического выполнения таблицы прогресса устаревают, и любая оценка «где отстаём» (сравнение источников, планирование слота) строится на неверных данных. У автора промах всплыл при сравнении двух курсов: карточки не отражали пройденное. Дробь против объёма превращает «в работе» в измеримую позицию относительно финиша — и делает слот саморазвития измеримым из артефактов, а не только из внешнего учёта.

**Как применять:**

- В конце учебного блока — записать в журнал сессии, что фактически пройдено (какой раздел/глава).
- Отразить в карточке источника: строка в «Прогресс» + сводная дробь «пройдено X/N».
- **Требует знаменателя:** в карточке должен быть зафиксирован общий объём источника (N). Нет N — прогресс неполон; добрать N при первом же обновлении.
- **Знаменатель — полный план источника; бери родной индикатор прогресса** (% и оглавление на странице курса, оглавление книги). Когда модули открываются поэтапно, не путай текущий видимый список с общим объёмом. Если платформа сама даёт процент — опирайся на него, а не на самодельную дробь из прокси.

### Таблицу «Прогресс» ведёт agent-writer

Ведение таблицы «Прогресс» карточек источников принадлежит **agent-writer** (агент обновляет в сессии по факту), тогда как учебные заметки остаются engineer-writer. Это и есть первый носитель класса `mixed` (INV-19): внутрифайловая граница — таблица прогресса за агентом, проза за владельцем. Уточнение к ADR-0020.
