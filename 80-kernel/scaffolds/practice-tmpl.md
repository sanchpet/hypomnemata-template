# Карточка практики — указатель, не скелет

Шаблон карточки практики саморазвития живёт в `30-knowledge/systems-thinking/new-practice-learning-meta-model.md` — [[new-practice-learning-meta-model|Мета-модель освоения новой практики]].

Она стоит там намеренно: мета-модель есть **предмет знания** (по руководству МИМ «Практики саморазвития»), а не оснастка агента, и потому живёт среди карточек знания, а не среди скелетов. Этот файл существует только затем, чтобы поиск шаблона в каталоге скелетов не заканчивался ничем.

Готовая карточка кладётся в `30-knowledge/systems-thinking/practices/`. Степень мастерства и номер `P-NNN` присваиваются в [[practices-tracker|трекере практик]] на сессии стратегирования, а не при создании карточки.
